# PLO — Practice Playbooks

Internal checklists and procedures for Parker Law Office.

## Structure

- **`playbooks/`** — Step-by-step procedures for common workflows
- **`checklists/`** — Quick-reference checklists for recurring tasks

## How to Use

Each playbook is a simple Markdown file you can read on GitHub or print out. Edit them anytime — GitHub tracks every change so nothing is lost.
