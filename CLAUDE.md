# CLAUDE.md — Instructions for Claude Code

## About This Repo

This is the internal playbook repository for Parker Law Office (PLO). It contains practice procedures, checklists, and workflow documentation.

## Structure

- `playbooks/` — Step-by-step procedures for common workflows
- `checklists/` — Quick-reference checklists for recurring tasks

## Guidelines

- All documents are written in Markdown
- Keep language plain and action-oriented (numbered steps, bullet points)
- Each playbook should have clear sections with headers
- Checklists use `- [ ]` checkbox format so they can be printed or tracked on GitHub
- Do not include any client names, case details, or confidential information in this repo
