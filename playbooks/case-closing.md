# Case Closing Procedure

## Before Closing

1. Confirm all work is completed and final billing sent
2. Collect any outstanding balances
3. Return original documents to client
4. Send closing letter to client

## File Management

1. Remove from active case list
2. Organize and index the file for storage
3. Note destruction/retention date per retention policy
4. Move to closed files (physical and/or digital)

## Follow-Up

1. Request client review/testimonial (if appropriate)
2. Add to mailing list for firm updates (with consent)
3. Note any future dates to calendar (e.g., appeal deadlines)
